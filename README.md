# dmenu - dynamic menu

dmenu is an efficient dynamic menu for X ([suckless.org](https://tools.suckless.org/dmenu/)).

# This build

Based on version 5.0.

Patch:

* [xresources](https://tools.suckless.org/dmenu/patches/xresources/): lets Xresources handle color.

# Installation

```
make
sudo make install
```
